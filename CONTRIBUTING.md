# Contribuição

## Regras

- Alterações pequenas e revisáveis.
- Commits em inglês ou português.
- Não incluir dados pessoais ou clínicos reais.
- Não adicionar IA sem uma análise de segurança separada.
- Todo texto médico ou farmacêutico deve indicar uma fonte verificável.

## Verificação

```bash
npm ci
npm run lint
npm run test
npm run build
```

## Commits

Usar mensagens no formato:

```text
tipo: descrição curta

- detalhe opcional
- motivo opcional
```
