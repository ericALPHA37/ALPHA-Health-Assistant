# ALPHA Health Assistant

Um MVP gratuito e auditável para fornecer **informação geral de saúde**, com segurança, privacidade e transparência.

> Esta aplicação não oferece diagnósticos, prescrição ou aconselhamento médico individualizado. Em caso de emergência, contacte imediatamente os serviços locais de urgência.

## Estado

- Front-end React + TypeScript + Vite
- Funcionalidade local e demonstrativa, sem chave de API
- Dados clínicos ou médicos **não serão inventados**
- Sem armazenamento em servidor
- Deploy planeado para GitHub Pages

## Objetivos

1. Procurar informação geral organizada e citável.
2. Mostrar limitações e sinais de atenção.
3. Funcionar sem custos recorrentes.
4. Permitir auditoria completa e replicação.

## Inicialização rápida

Requisitos: Node.js 22 LTS e npm 10+.

```bash
npm install
npm run dev
```

Depois abra `http://localhost:5173/ALPHA-Health-Assistant/`.

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — compilação de produção
- `npm run lint` — análise estática
- `npm run test` — testes automatizados
- `npm run preview` — pré-visualização da compilação
