# Política de segurança

Este projeto é uma demonstração, não uma ferramenta clínica validada.

Consulte [Segurança, privacidade e comunicação de vulnerabilidades](docs/SECURITY.md#reportar-uma-vulnerabilidade).

Não publique vulnerabilidades exploráveis, segredos ou dados pessoais/clínicos em issues. Ainda não existe canal privado confirmado; a política explica como solicitar um sem expor detalhes sensíveis.
