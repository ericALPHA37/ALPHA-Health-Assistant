# Segurança e privacidade

## Dados

Na versão inicial:

- não cria contas;
- não envia consultas a servidores;
- não usa rastreamento;
- não usa cookies;
- não regista texto no servidor;
- não lê dados médicos de outros sistemas.

## Risco clínico

O projeto não deve:

- diagnosticar;
- recomendar medicamentos;
- substituir consulta profissional;
- prometer emergência, prescrição ou interpretação de exames.

## Dependências

Todas as dependências devem ser:

- fixadas por lockfile;
- analisadas por auditorias locais;
- atualizadas por revisão humana;
- usadas sem fornecimento automático de dados pessoais.

## Reportar vulnerabilidades

Se adicionarmos um canal público, não publique vulnerabilidade sensível antes de uma correção coordenada.
