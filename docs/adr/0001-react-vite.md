# ADR 0001 — React + Vite

## Estado

Aceite.

## Contexto

O projeto precisa ser simples de replicar, gratuito e adequado à publicação no GitHub Pages.

## Decisão

Usar React com TypeScript e Vite.

## Motivo

- Ecossistema maduro.
- Compilação local gratuita.
- Aumento gradual para interação rica.
- Configuração pequena e auditável.

## Consequências

- Necessita Node.js para desenvolvimento.
- Aplicação renderizada no navegador.
