# ADR 0002 — Modo local sem custos

## Estado

Aceite.

## Contexto

Não existe chave de IA própria e o projeto deve iniciar sem custos recorrentes.

## Decisão

A primeira versão usa somente dados e respostas locais definidos por manutenção humana.

## Motivo

- Evita custos e dependência externa.
- Permite auditoria mais simples.
- Reduz risco de alucinação clínica.

## Consequências

- Funcionalidade limitada.
- Atualizações de conteúdo exigem revisão.
